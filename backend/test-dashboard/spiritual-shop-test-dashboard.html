How admin access works

There is one sign-in system. The dashboard reads the verified Firebase ID token's admin: true custom claim. A normal customer only sees the customer panel. An admin sees the extra admin panel after refreshing their token or signing in again.

Do not create an admin field in the users document. Admin role is a server-controlled custom claim.

Add a product

Creates a NEW product using the agreed schema. Product images are uploaded to Storage at products/{productId}/{filename}; only the Storage paths are saved in images. Prices are entered in rupees and stored as integer paise. This test form does not edit existing products or stock.

Files upload to Firebase Storage. The Storage rules are authoritative; a denied upload is a security/rules issue, not a reason to weaken rules.
